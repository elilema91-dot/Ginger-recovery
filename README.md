# 강차 일정 (아이폰 구독용)

`calendar.ics` 는 강차 회원·일정 페이지의 일정을 아이폰 캘린더에서 구독하기 위한 파일입니다.
공개 저장소라서 회원 이름은 가운데 글자를 가려서(예: 박*영) 넣습니다.
Claude가 일정이 바뀔 때마다 이 파일을 새로 만들어 올립니다 (`make_ics.py`).

## 종류별 파일 (색을 따로 정하려면 각각 구독)
- `member.ics` 강차 회원 (초록)
- `riding.ics` 강차 라이딩 (빨강)
- `life.ics` 강차 생활 (주황) — 회원·라이딩 말고 나머지
- `calendar.ics` 전체 (한 가지 색)

## 자동 동기화
`sync.enc` 는 회원·일정 페이지로 옮길 일정 원본(암호화). 키는 저장소에 없습니다.
매시간 자동 작업이 이 파일을 풀어서 회원·일정 페이지에 맞춥니다.
